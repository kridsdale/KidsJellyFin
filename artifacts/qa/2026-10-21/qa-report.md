## Observed behavior

- Existing saved-adult Jellyfin fallback unlocked the phone app. The four native destinations worked. Returning from the Home screen relocked parent access. Settings exposed separate connection/setup/sign-out/family tools.
- Parent-control restoration then displayed **“The server returned HTTP503. No success was confirmed. Refresh before retrying a change.”** Settings reported unavailable parent access. Start countdown remained disabled. This access failure was observed; its cause was not investigated or repaired.
- The child app opened **“A grown-up needs to set up your shows.”** No catalog or media appeared. Because valid restricted setup was not established in this run, this recovery state is **not** labeled a C-009 launch defect.
- The phone Shows tab displayed a real Kid TV catalog with explicit read-only connection guidance. Review inbox displayed **“No reviews loaded. Pull to refresh.”** That is not accepted as evidence of an empty canonical queue or a pending-entry handoff.
- The actual TV Parents gate did not open via the bounded available keyboard path; a physical tap failed with a QA-tool orientation error. Consequently the sidebar, PIN/phone flow and underlying playback continuity were not observed. No candidate app was installed to replace the baseline.
