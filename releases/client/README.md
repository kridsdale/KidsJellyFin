# Client release records

Each directory is named with the canonical Pacific release version `YYYYMMDD-HHMM` and contains an immutable `manifest.json` generated by `Scripts/Kids/release_metadata.py`.

Release manifests track source and artifact identity; app bundles, archives, screenshots, private logs, simulator data, and credentials are not stored here. Published tags use `client-vYYYYMMDD-HHMM` and are never moved.
